# Code of conduct

HomeIsland is a small project run by volunteers. Everyone taking part — in
issues, pull requests, discussions or elsewhere in the project's spaces — is
expected to:

- be respectful and patient, especially with newcomers;
- assume good intentions and discuss ideas, not people;
- give and accept constructive criticism;
- keep discussions on topic.

Not acceptable: harassment, insults, discriminatory language or behaviour,
personal attacks, publishing others' private information, and sustained
disruption.

Maintainers may edit or remove contributions and temporarily or permanently
block participants who do not follow these rules.

To report a problem privately, contact the maintainers through a private
GitHub security advisory on this repository (see [SECURITY.md](SECURITY.md)) and
mention that it is a conduct report. Reports are handled confidentially.
